# 蓝桥杯单片机 PCF8591 代码实操

PCF8591作用就是**提供ADC，DAC**

同样，比赛中先导入官方给的数据包内不完整的驱动文件

翻阅芯片手册，查看寄存器操作地址

先把引脚补全

```c
sbit scl = P2^0;
sbit sda = P2^1;
```



先写ADC函数（一般就是将读取到的光敏电阻等的电压转换为0-255的模拟值，显示出来）

```c
float PCF8591_ADC(unsigned char addr)
{
	float temp;
	I2CStart();
	I2CSendByte(0x90); //写入模式
	I2CWaitAck();
	I2CSendByte(addr); //写入地址
	I2CWaitAck();
	
	I2CStart();
	I2CSendByte(0x91); //读取模式
	I2CWaitAck();
	temp = I2CReceiveByte();
	I2CSendAck(1); //告诉芯片读够了
	I2CStop();
	temp = temp * 100 / 51; // temp/255*5*100=temp*100/51
	return temp;
}
```



再写DAC函数（这个就是把模拟量变回电压储存）

```c
void PCF8591_DAC(unsigned char dat)
{
	I2CStart();
	I2CSendByte(0x90);
	I2CWaitAck();
    
	I2CSendByte(0x41); //DAC写入地址
	I2CWaitAck();
    
	I2CSendByte(dat);
	I2CWaitAck();
	I2CStop();
}
```



光敏电阻的addr是0x01, 滑动电阻Rb2是0x03才对，一般常考这两个
