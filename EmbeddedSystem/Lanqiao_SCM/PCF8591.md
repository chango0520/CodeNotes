# 蓝桥杯单片机 PCF8591 代码实操

PCF8591作用就是**提供ADC，DAC**

同样，比赛中先导入官方给的数据包内不完整的驱动文件

翻阅芯片手册，查看寄存器操作地址

先把引脚补全

```c
sbit scl = P2^0;
sbit sda = P2^1;
```



先写ADC函数（一般就是将读取到的光敏电阻等的电压转换为0-255的模拟值，显示出来）

```c
unsigned int PCF_ADC(unsigned char addr){
	unsigned int temp;
	I2CStart();
	I2CSendByte(0x90);
	I2CWaitAck();
	I2CSendByte(addr);
	I2CWaitAck();

	I2CStart();
	I2CSendByte(0x91);
	I2CWaitAck();
	//temp=I2CReceiveByte();
	//I2CSendAck(0);
	temp=I2CReceiveByte();
	I2CSendAck(1);
	I2CStop();

	temp=temp*100/51;
	return temp;
}
```



再写DAC函数（这个就是把模拟量变回电压储存）

```c
void PCF_DAC(unsigned int dat){
	unsigned char temp = dat*51/100;
	
	I2CStart();
	I2CSendByte(0x90);
	I2CWaitAck();
	I2CSendByte(0x40);
	I2CWaitAck();
	I2CSendByte(temp);
	I2CWaitAck();
	I2CStop();
}
```



光敏电阻的addr是0x01, 滑动电阻Rb2是0x03才对，一般常考这两个
