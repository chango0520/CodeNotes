# 蓝桥杯单片机 DS1302 代码实操

DS1302作用就是**提供时钟，进行计时**

比赛中先导入官方给的数据包内不完整的驱动文件

翻阅芯片手册，查看寄存器操作地址

添加引脚

```c
sbit SDA = P2^3;
sbit SCK = P1^7;
sbit RST = P1^3;
```

添加读写RTC函数

```c
unsigned char Time[3] = {12, 50,00};  //此处是初始时间

void W_Ds1302(unsigned char *Time)
{
	unsigned char temp;
	Write_Ds1302_Byte(0x8e, 0x00);  //开启写保护
	temp = Time[0] / 10 * 16 + Time[0] % 10; 
	Write_Ds1302_Byte(0x84, temp); //时
	temp = Time[1] / 10 * 16 + Time[1] % 10;
	Write_Ds1302_Byte(0x82, temp); //分
	temp = Time[2] / 10 * 16 + Time[2] % 10;
	Write_Ds1302_Byte(0x80, temp); //秒
	Write_Ds1302_Byte(0x8e, 0x80); //关闭写保护
}

void R_Ds1302(unsigned char *Time)
{
	unsigned char temp;
	temp = Read_Ds1302_Byte(0x85); //时
	Time[0] = temp / 16 * 10 + temp % 16;
	temp = Read_Ds1302_Byte(0x83); //分
	Time[1] = temp / 16 * 10 + temp % 16;
	temp = Read_Ds1302_Byte(0x81); //秒
	Time[2] = temp / 16 * 10 + temp % 16;
}
```



此处涉及到的还有个知识点就是**BCD码转换**， 把一个10进制的数转换为16进制数，应该把每一位单独处理，例如十进制就是先算该位在16占的份数（即temp / 16），在乘以总数10 (相当于等价转换到10进制中)，即可算出在十进制中的该数，反之同理

应用的话，先在 **main() **函数内调用 **W_Ds1302()** 进行写入初始时间， 开始自动计时，然后我们只需要在使用的地方进行读取即可



### 进阶

##### 12/24小时制切换

根据Datasheet内的寄存器信息，在读取小时的同一个地址还可以实现切换小时制模式

```c
hour_reg = 0xA0 | DEC_to_BCD(hour_val);
Write_Ds1302_Byte(0x84, hour_reg);
```

##### 写入/读取日期

其实和时分秒的方法是一样的，不过就是寄存器地址不同（0x84）

```c
void W_Ds1302_Date(unsigned char *Date)
{
    unsigned char temp;

    Write_Ds1302_Byte(0x8e, 0x00);  // 解除写保护

    // 写日（寄存器0x86）
    temp = DEC_to_BCD(Date[0]);
    Write_Ds1302_Byte(0x86, temp);

    // 写月（寄存器0x88）
    temp = DEC_to_BCD(Date[1]);
    Write_Ds1302_Byte(0x88, temp);

    // 写年（寄存器0x8C）
    temp = DEC_to_BCD(Date[2]);
    Write_Ds1302_Byte(0x8C, temp);

    Write_Ds1302_Byte(0x8e, 0x80);  // 设置写保护
}
```
