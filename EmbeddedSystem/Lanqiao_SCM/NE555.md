# 蓝桥杯单片机 NE555 代码实操



堪称最伟大的芯片（似乎）

常考的是通过频率来测量环境湿度

该芯片要么使用定时器，要么就要使用PCA进行定时测量频率

## PCA

先写初始化函数

```c
void PCA_Init(){
    P_SW1 &= 0xcf;
    P_SW1 |= 0x10;
    CMOD = 0x06;
    CR=1;
    CL=CH=CF=0;
}
```

再写采集配置

```c
if(++cnt_ne555 == 1000) //1秒采集一次
{
    cnt_ne555 = 0;
    CR = 0; //停止计数
    data_NE = (CH << 8) | CL; //组成一个16位数据
    CH = CL = 0; //归零，重新计数
    CR = 1; //开始计数
}
```

3.最后转换频率为湿度值

公式为：湿度=2*ne555的频率/45+ 10/9

```c
ne555_f = (unsigned int)(2 * data_NE / 45  + 10 / 9);
```



## 定时器0

1.修改定时器0为计数器模式（TMOD修改为|=0x04，TH0=TL0=0）

```c
void Timer0_Init(void)  //若是需要ne555则是计数器模式
{
	AUXR &= 0x7F;   // 定时器时钟12T模式
	TMOD |= 0x04;   // 设置为计数器模式
	TL0 = TH0 = 0;  // 计数清零，计数脉冲个数
	TR0 = 1;        // 开始计数
	TF0 = 0;	
}
```

2.定时器0中断函数内书写测量时间等配置

```c
if(++cnt_ne555 == 1000) //1秒采集一次
{
    cnt_ne555 = 0;
    TR0 = 0; //停止计数
    data_NE = (TH0 << 8) | TL0; //组成一个16位数据
    TH0 = TL0 = 0; //归零，重新计数
    TR0 = 1; //开始计数
}
```

3.最后转换频率为湿度值

公式为：湿度=2*ne555的频率/45+ 10/9

```c
ne555_f = (unsigned int)(2 * data_NE / 45  + 10 / 9);
```



其实两只方法一样，只是初始化函数和寄存器名字不同，平时常用PCA操作NE555，定时器0常用于整个系统的计时
