# 蓝桥杯单片机 DS18B20 代码实操

DS18B20的作用是测量环境温度

和DS1302相同，先导入官方驱动文件

查阅手册，获取寄存器操作地址

编写读取温度函数

```c
float Read_Temp()
{
	unsigned char H, L;
	float Temperature;
	
	init_ds18b20();
	Write_DS18B20(0xcc); //跳过rom
	Write_DS18B20(0x44); //开启温度转换
	//Delay_ms(750); 
	
	init_ds18b20();
	Write_DS18B20(0xcc); //同样跳过rom
	Write_DS18B20(0xbe); //读取温度
	
	L = Read_DS18B20(); //低8位数据
	H = Read_DS18B20(); //高8位数据
	Temperature = ((H << 8) | L) * 0.0625; //合并 ，要*0.0625就是/16（因为这里是有多少个0.0625来测的）
	return Temperature;
}
```

以上是正常测量温度的写法，国赛还考过测量负温度，只需要加一些代码即可。

```c
float Read_Temp()
{
	unsigned char H, L;
	unsigned int Temp;
    float T;
	bit negative;
	init_ds18b20();
	Write_DS18B20(0xcc); //跳过rom
	Write_DS18B20(0x44); //开启温度转换
	//Delay_ms(750); 
	
	init_ds18b20();
	Write_DS18B20(0xcc); //同样跳过rom
	Write_DS18B20(0xbe); //读取温度
	
	L = Read_DS18B20(); //低8位数据
	H = Read_DS18B20(); //高8位数据
	Temp = (H << 8) | L ; //合并 
    if(H & 0xf8){
        negative=1;
        Temp = ~Temp+1;
    }
    T = Temp * 0.0625; //要*0.0625就是/16（因为这里是有多少个0.0625来测的）
    if(negative) T = -T;
	return T;
}
```

使用时直接强转(这种是只要整数，比赛一般也是只要整数)

```c
unsigned char temp;
temp = (unsigned char)Read_Temp();
```
